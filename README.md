# 🛍️ Amazon Clone Project

This is a front-end clone of the Amazon website, built with guidance from a YouTube tutorial. The goal was to practice HTML, CSS while learning layout design and responsiveness.

## 🔧 Tech Stack
- HTML
- CSS

## 🚀 Features
- Home page layout similar to Amazon
- Product cards and grid system
- Responsive design
- Hover effects and navigation bar

## 📁 Folder Structure

📁 Project Files
The project includes `index.html`, `style.css`, and an `images` folder. Everything is organized for easy access and readability.


## 🎯 What I Learned
- Flexbox and Grid layout
- Basic responsive design
- Organizing and structuring a project
- How to follow a real-world tutorial project

## 📌 How to View
You can clone the repository and open `index.html` in your browser.
